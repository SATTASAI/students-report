# ระบบรายงานผลการเรียน โรงเรียนบ้านป่าเด็ง (students-report)

เว็บไซต์: https://grades.banpadengschool.ac.th

ระบบบันทึกคะแนนและรายงานผลการเรียนระดับ ป.1–ป.6 ทำงานเป็น Cloudflare Worker ตัวเดียว ใช้ฐานข้อมูล D1 และบัญชีผู้ใช้ร่วมกับระบบบริหารโรงเรียน (banpadeng-school-db)

## ความสามารถ

- **ครูผู้สอน** ตั้งโครงสร้างคะแนนตามตัวชี้วัดได้ 3 วิธี คือพิมพ์เอง วางจากเอกสารหลักสูตร หรือเลือกจากคลังตัวชี้วัด และคัดลอกโครงสร้างจากห้องอื่นได้
- **สมุดคะแนน** เป็นตารางแบบ Excel กด Enter เพื่อเลื่อนลงไปคนถัดไป วางช่วงคะแนนจาก Excel ได้ บันทึกอัตโนมัติ และกันคะแนนเกินเต็มหรือไม่ใช่ตัวเลข
- **ตัดเกรดรายปี** 8 ระดับ คะแนนรวมไม่ปัดเศษ (79.99 ได้ 3.5) สัดส่วนคะแนนเก็บกับปลายภาคตั้งแยกรายวิชาได้
- **ผลพิเศษ** เวลาเรียนไม่ถึง 80% ได้ มส อัตโนมัติ คะแนนไม่ครบได้ ร บันทึกสอบแก้ตัวได้ (แก้ 0 หรือ มส ได้สูงสุด 1) และบันทึกเรียนซ้ำได้
- **ตัวชี้วัดไม่ผ่าน** ระบบแสดงและเตือน แต่ไม่บล็อกการให้เกรด
- **ยืนยันผล** แล้วรายวิชาจะถูกล็อก ผู้ดูแลปลดล็อกได้
- **ครูประจำชั้น** ประเมินคุณลักษณะอันพึงประสงค์ 8 ข้อ, การอ่าน คิดวิเคราะห์ และเขียน, สมรรถนะ 5 ด้าน และกิจกรรมพัฒนาผู้เรียน บันทึกวันขาดเรียนของเด็กที่ขาดบ่อย และพิมพ์หนังสือแจ้งผู้ปกครองได้
- **เอกสาร** ปพ.5, ปพ.6, ปพ.1 (ฉบับตรวจทาน), รายงานสรุปผลสัมฤทธิ์ และหนังสือแจ้งขาดเรียน สั่งพิมพ์หรือบันทึกเป็น PDF ได้ และเลือกใช้เลขไทยได้
- **ส่งออก** เป็น Excel รายห้องหรือทุกห้อง และ CSV แบบ 1 แถวต่อ 1 วิชา

## ติดตั้งครั้งแรก

1. **สร้าง Worker จาก repo นี้** ใน Cloudflare ไปที่ Workers & Pages → Create → Import a repository → เลือก `SATTASAI/students-report` แล้วตั้งชื่อ Worker ว่า `students-report`
2. **ตั้ง secret `JWT_SECRET`** ที่ Worker → Settings → Variables and Secrets → Add → ประเภท Secret ชื่อ `JWT_SECRET` ค่าต้อง**เหมือนกับ** `JWT_SECRET` ของ banpadeng-school-db ทุกตัวอักษร
3. **ไม่ต้องผูก D1 เอง** เพราะประกาศไว้ใน `wrangler.jsonc` แล้ว (`DB` → `banpadeng_school_db`)
4. เปิดเว็บแล้วเข้าสู่ระบบด้วยบัญชีผู้บริหาร ระบบจะสร้างตาราง `gr_*` ให้เองตอนที่ใช้งานครั้งแรก
5. ไปที่ **ตั้งค่ารายวิชา → เริ่มต้นปีการศึกษา** แล้วทำตามขั้นตอนที่หน้านั้นแสดง

> ถ้าหน้าเว็บขึ้นว่า "ยังไม่ได้ตั้งค่า JWT_SECRET ของ Worker" แสดงว่ายังไม่ได้ทำขั้นตอนที่ 2

## ข้อมูลที่ใช้ร่วมกับระบบบริหารโรงเรียน (อ่านอย่างเดียว)

| ข้อมูล | ตาราง |
|---|---|
| บัญชีผู้ใช้ / สิทธิ์ | `users` (superadmin, executive ถือเป็นผู้ดูแลโดยอัตโนมัติ) |
| ปีการศึกษา / ภาคเรียน | `academic_years`, `academic_terms` |
| นักเรียน / ห้องเรียน | `students`, `student_details`, `student_enrollments` (ใช้ภาคเรียนล่าสุดของปี) |
| ครูประจำชั้น (ดึงครั้งแรก) | `learner_class_assignments` |

ระบบนี้**เขียน**เฉพาะตารางที่ขึ้นต้นด้วย `gr_` เท่านั้น ยกเว้น 3 จุดที่ใช้ร่วมกับ school-db:
- `system_settings` เก็บเลขเวอร์ชันของตารางไว้ 1 แถว (`students_report_schema`)
- `auth_login_throttles` นับจำนวนครั้งที่ล็อกอินผิด ใช้ร่วมกับ school-db
- `users.last_login_at` อัปเดตทุกครั้งที่เข้าสู่ระบบ

ตาราง `gr_` ไม่มี foreign key ชี้ไปยังตารางของระบบบริหารฯ จึงไม่ทำให้การลบผู้ใช้หรือนักเรียนในระบบนั้นล้มเหลว

## ก่อนเปิดภาคเรียนที่ 2

- จัดชั้นเรียนภาคเรียนที่ 2 ในระบบบริหารโรงเรียนก่อน รายชื่อในสมุดคะแนนจะเปลี่ยนตามภาคเรียนล่าสุดเอง ถ้ายังไม่จัด ระบบจะใช้รายชื่อของภาคเรียนที่ 1
- นักเรียนที่ย้ายออกหรือย้ายห้องระหว่างปีจะไปอยู่ท้ายตาราง ไม่มีเลขที่ แต่คะแนนเดิมยังอยู่ครบ

## วันหยุดปี 2570 (ตรวจสอบ 27 ตุลาคม 2569)

โค้ด `src/lib/thai-holidays.js` คำนวณวันหยุดประจำปี 2570 ได้ตรงกับวันที่ตรวจสอบ จึงไม่ต้องเปลี่ยนสูตรหรือย้ายวันหยุด เพิ่มการทดสอบรายการทั้งปีใน `tests/thai-holidays.test.mjs` และตรวจว่า API ไม่นับ 22 กุมภาพันธ์ 2570 เป็นวันเรียน

- มาฆบูชา 21 ก.พ. → ชดเชย 22 ก.พ.; วิสาขบูชา 20 พ.ค.
- อาสาฬหบูชา 18 ก.ค.; เข้าพรรษา 19 ก.ค.; ชดเชยอาสาฬหบูชา **20 ก.ค.** เพราะ 19 ก.ค. เป็นวันหยุดราชการอยู่แล้ว
- ปิยมหาราช 23 ต.ค. → ชดเชย 25 ต.ค.; วันพ่อแห่งชาติ 5 ธ.ค. → ชดเชย 6 ธ.ค.
- ใช้ปฏิทินราชการสำหรับโรงเรียน: ไม่ใส่วันแรงงาน 1 พ.ค. และวันชดเชยแรงงาน 3 พ.ค. อัตโนมัติ
- วันพืชมงคลและวันหยุดพิเศษตามมติ ครม. ต้องตรวจประกาศเฉพาะปีแล้วให้ฝ่ายวัดผลเพิ่มเอง ยังไม่กำหนดวันที่จากการคาดการณ์

แหล่งตรวจสอบ: [ประกาศ ก.ล.ต. ปี 2570](https://www.sec.or.th/TH/Pages/News_Detail.aspx?SECID=13306) ใช้ยืนยันวันที่ร่วมกัน โดยประกาศนี้เป็นวันหยุดธุรกิจหลักทรัพย์ ไม่ใช่รายการวันหยุดราชการทั้งหมด; [หลักเกณฑ์วันหยุดชดเชยของสำนักเลขาธิการคณะรัฐมนตรี](https://www.soc.go.th/?page_id=1045) ใช้วันทำการถัดไป; [ปฏิทินจันทรคติ กรกฎาคม 2570](https://myhora.com/calendar/thai-07-2570.aspx) ตรวจวันเข้าพรรษาและวันชดเชย

ปฏิทินแยกสีตามสถานะวัน:

- **สีแดง**: วันหยุดราชการ วันหยุดที่ฝ่ายวัดผลเพิ่ม และเสาร์–อาทิตย์
- **สีเหลือง**: วันสำคัญที่ไม่ใช่วันหยุด เช่น วันภาษาไทยและวันวิทยาศาสตร์ ยังนับเป็นวันเรียนเมื่ออยู่ในภาคเรียน
- วันสำคัญที่ตรงวันหยุดใช้ช่องสีแดงและแสดงชื่อวันสำคัญประกอบ ไม่มีการเพิ่มวันชดเชยให้วันสำคัญ
- เพิ่มวันสำคัญสำหรับโรงเรียนใน `src/lib/thai-observances.js` และส่งผ่าน `GET /api/calendar` ใน `important_days` แยกจาก `holidays` ไม่เขียนข้อมูลวันหยุด ไม่ล้างบันทึกมาเรียน และไม่เปลี่ยนจำนวนวันเรียน วันเด็กใช้เสาร์ที่สองของเดือนมกราคม วันออกพรรษา/ลอยกระทงคำนวณตามจันทรคติทุกปี
- วันครูแสดงเป็นวันสำคัญ หากโรงเรียนประกาศหยุดให้ฝ่ายวัดผลเพิ่มวันหยุดเอง (ปี 2570 ตรงเสาร์ 16 ม.ค. จึงแสดงบนช่องวันหยุดประจำสัปดาห์ ไม่มีการชดเชยอัตโนมัติ)

วันที่ตายตัวอ้างอิง [รายการวันสำคัญกรมปศุสัตว์](https://manage.dld.go.th/index.php/th/news-head/relations/calendar2569) โดยนำมาใช้เฉพาะวันที่คงที่ ไม่ยกวันที่จันทรคติจากปี 2569 มาใช้ปี 2570; วันครูอ้างอิง [คุรุสภา](https://elibrary.ksp.or.th/index.php?id_article=195&lvl=cmspage&pageid=4); วันออกพรรษาปี 2570 อ้างอิง [สำนักงานพระพุทธศาสนาจังหวัดแพร่](https://pre.onab.go.th/th/content/category/detail/id/73/iid/9936)

เทศกาลเพิ่มเติม: วาเลนไทน์ ฮาโลวีน คริสต์มาสอีฟ สารทไทย ตักบาตรเทโว รวมถึงเทศกาลจีน วันจ่าย–วันไหว้–ตรุษจีน โคมไฟ เช็งเม้ง ไหว้บ๊ะจ่าง สารทจีน ไหว้พระจันทร์ และกินเจครบ 9 วัน ส่วนปีใหม่ สงกรานต์ ลอยกระทง และคริสต์มาสมีอยู่แล้ว เทศกาลทั้งหมดเป็นข้อมูลประกอบ ไม่เพิ่มวันหยุดหรือวันชดเชย หากตรงวันหยุดใช้สีแดงตามสถานะวันจริง

วันที่เทศกาลจีนใน `src/data/chinese-festivals.js` ตรวจเทียบปฏิทินหอดูดาวฮ่องกง [2569](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2026e.pdf), [2570](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2027e.pdf), [2571](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2028e.pdf) รองรับปีการศึกษา 2569–2570 ที่ข้ามไปต้นปีถัดไป ไม่ใช้สูตรเดือนจันทรคติไทยแทนเดือนจีน และไม่คาดเดาวันที่จีนของปีที่ยังไม่มีในตาราง ต้องเพิ่มปีที่ตรวจสอบแล้วก่อนใช้ต่อ ส่วนวันที่ตายตัวและวันจันทรคติไทยยังคำนวณทุกปีตามเดิม

ตัวอย่างปี 2570: วันจ่าย 4 ก.พ., วันไหว้ 5 ก.พ., ตรุษจีน 6 ก.พ., เช็งเม้ง 5 เม.ย., ไหว้บ๊ะจ่าง 9 มิ.ย., สารทจีน 16 ส.ค., ไหว้พระจันทร์ 15 ก.ย., กินเจ 30 ก.ย.–8 ต.ค. (ตาม [เกณฑ์วันที่ 1–9 เดือน 9 จีนของ ททท.](https://thai.tourismthailand.org/Articles/vegetarian-festival-24)) กำหนดงานเฉพาะพื้นที่อาจรวมวันเตรียมงานก่อนหรือวันปิดงานหลังช่วงนี้

ข้อมูลในฐานข้อมูลเว็บไซต์อาจต่างจากผลคำนวณหากมีการแก้ไขหรือลบไว้แล้ว: ผู้ดูแลตรวจที่ **ตั้งค่ารายวิชา → ปฏิทินวันหยุด** โดยเลือกปีการศึกษาที่ครอบคลุมวันที่นั้น ปุ่ม **เติมวันหยุดราชการ** เติมเฉพาะวันที่ขาด ไม่ทับชื่อที่โรงเรียนตั้งไว้ และไม่ลบวันหยุดที่เพิ่มเอง การตรวจโค้ดครั้งนี้ไม่ได้ตรวจหรือแก้ฐานข้อมูลเว็บไซต์จริง
